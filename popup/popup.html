자동 수집 안내

매일 한국 시간 새벽 5시에 알림 중복 방지와 자동 수집의 일시 중지·재시도 상태가 초기화됩니다. 보상 기록은 유지됩니다. 방송 탭을 음소거하고 재생을 확인한 뒤 이전 탭으로 돌아옵니다. 재생 중 치지직·트위치 플레이어는 음소거를 해제합니다. 실패하면 제한적으로 재시도합니다. 치지직은 일반 방송을 보고 있어도 별도의 수집 탭에서 동작합니다. 트위치는 다른 트위치 방송 탭을 닫아 주세요. 로그인·게임 계정 연결은 직접 필요합니다. 토글을 끄면 자동으로 만든 방송 탭을 닫습니다. 수집 탭을 직접 닫거나 이동하면 일시 중지되며, 토글을 껐다 켜면 재개합니다.

치지직과 트위치는 한 캠페인을 마친 뒤 다음 캠페인으로 이동합니다. 영상 재생과 서버 시청 시간 적립은 별도로 확인합니다. 트위치 보상 자동 수령은 ‘트위치 자동 수령’ 설정을 따릅니다. 치지직·SOOP 쿠폰 코드 확인·복사와 게임 내 입력은 직접 진행해 주세요.
