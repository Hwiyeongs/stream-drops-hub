# Stream Drops Hub 수정본 v1.4.5

원본과 별도 폴더에서 작업한 Chrome 확장프로그램입니다.

## 불러오기

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 기존 Stream Drops Hub가 켜져 있다면 꺼 두세요. 두 확장프로그램이 동시에 수령을 시도하지 않도록 하기 위한 절차입니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `stream-drops-hub-fixed` 폴더를 선택합니다. ZIP을 받은 경우 먼저 압축을 풉니다.
5. **Stream Drops Hub - 수정본**을 열어 조회 상태를 확인합니다. 자동 수령 기본값은 OFF이며 설정에서 켤 수 있습니다.

새 폴더로 등록한 확장프로그램은 기존 설치와 설정·기록 저장소가 분리될 수 있습니다. 기존 확장프로그램의 기록은 삭제하지 않았습니다. 같은 확장 ID의 버전 업데이트인 경우에는 코드에 포함된 마이그레이션이 기존 쿠폰 기록을 보존합니다.

## 수정한 동작

- 트위치: 선택한 보상 인스턴스 ID로 수령 요청. 첫 번째 버튼 추정 클릭, 여러 번 클릭, 다른 탭의 수령 메시지를 성공으로 오인하는 경로 제거.
- 성공 확인: 성공으로 확인한 보상만 기록하고 목록에서 제거. 알 수 없는 응답·쿠폰 조회 실패는 성공으로 표시하지 않음.
- 자동 수령: OFF일 때 보관함 방문만으로 수령하지 않음. 알림과 수령 상태를 분리하고 실패를 재시도.
- 전체 수령: 남은 작업 저장. 팝업을 닫아도 계속 처리하며 브라우저 재시작 후 남은 작업을 재개. 실패한 항목은 재시도 가능.
- 쿠폰 기록: 코드 보관됨 / 코드 복사됨 / 인앱 수령 완료 구분. 복사 실패 시에도 이미 확보한 코드는 기록에 보존.
- 기록 저장: 항목별 저장으로 동시 쓰기 유실 방지. 자동 수령도 같은 기록 탭에 반영.
- 설정: 확인 주기 변경을 실제 알람에 적용. 초기 설정 로딩 중에는 입력을 잠금.
- 캐시: 실제 키로 구버전 캐시 삭제. 조회 실패는 정상 0개와 구별하고 마지막 목록에는 최신 조회 필요 표시.
- 날짜: 치지직은 획득 날짜 제한 없이 유효한 보상을 표시. SOOP은 날짜가 확인되면 기존 한국시간 오늘/어제 기준 유지. 날짜만 있는 쿠폰 만료일은 해당 날짜 23:59:59.999까지.
- UI: 인라인 오류 핸들러 제거, 안전한 텍스트 렌더링, 이미지 오류 대체 표시, 가로 넘침 수정.

## 확인한 범위

- 원본 17개 파일: 작업 전후 SHA-256 및 파일 수 일치.
- 회귀 테스트 28개 통과: 쿠폰 조회 실패, 수령 실패 재시도, 자동 수령 설정 변경, 동시 기록, 날짜 경계, 캐시 마이그레이션, 설정 알람, 전체 수령 재개, 발신자 검증, 응답 본문 타임아웃 등.
- 임시 Chromium UI 테스트: 탭 전환, 설정, 클립보드 복사, 실패한 쿠폰 유지, 정상 쿠폰 기록, HTML 텍스트 이스케이프, 레이아웃 확인.
- 별도 Chromium 프로필에 실제 확장프로그램 로드: 서비스워커, 실제 메시지 왕복, 5분 알람 반영, 팝업을 닫은 후 모의 쿠폰의 백그라운드 기록 확인.

실제 사용자 계정의 드롭스를 수령한 검증은 하지 않았습니다. Twitch/치지직/SOOP의 현재 서버 규격·보안 검증에 따른 실계정 수령 성공 여부는 별도 확인이 필요합니다. 트위치 요청이 거부되면 해당 카드를 남기고 보관함에서 확인하도록 안내합니다.

트위치 캠페인에 임의의 24시간 유예를 더하지 않습니다. 서버의 명시적 수령 기한이 있으면 그것을, 없으면 캠페인 종료일을 사용하므로 실제 서버의 별도 유예 규칙까지 검증한 것은 아닙니다.

## 개발 검증

Node.js 22 이상에서 이 폴더를 작업 디렉터리로 선택한 뒤 실행합니다. 추가 패키지 설치는 필요하지 않습니다.

```powershell
node tests/regression.test.js
```

브라우저 검증은 분리된 임시 프로필과 모의 데이터로 수행했으며 실제 로그인 쿠키를 사용하지 않았습니다.

## 참고 문서

백그라운드 이벤트·상태 저장 구조는 Chrome의 [서비스워커 이전 안내](https://developer.chrome.com/docs/extensions/develop/migrate/to-service-workers) 및 [서비스워커 이벤트 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/service-worker-events)를 참고했습니다.


## 이터널리턴 방송 감지 (v1.4.0)

설정 → 이터널리턴 드롭스 방송에서 **방송 감지 및 알림**을 켜세요. 치지직·SOOP의 해당 카테고리에서 실제 드롭스 표시가 있는 방송을 약 1분마다 확인합니다. 켜는 시점에 이미 방송 중인 채널도 대상입니다. 치지직 알림은 캠페인별로 중복을 막으며 마지막 감지부터 30일간 기록을 유지합니다. SOOP은 현재 방송 목록에 캠페인 ID가 없어 한국시간 기준 같은 카테고리에서 하루 한 번 알립니다.

**자동으로 방송 열기**도 켜면 플랫폼별 시청자 수가 많은 대상 방송 한 개를 백그라운드 탭으로 엽니다. 이미 대상 방송을 열어 두었다면 추가 탭을 만들지 않습니다. 두 설정의 기본값은 꺼짐입니다. 감지를 끄면 자동 열기도 중단되며 기존 탭은 닫지 않습니다.

브라우저가 실행 중이어야 하며 절전 상태에서는 확인이 늦어질 수 있습니다. 방송 페이지를 여는 기능으로, 자동 재생이나 드롭스 시청 시간 적립을 보장하지 않습니다. 알림은 운영체제의 브라우저 알림 허용 상태에 영향을 받습니다. 조회 실패는 설정에 표시하며 다음 주기에 재시도합니다.

검증: 기존 회귀 검사 28개와 방송 감지 검사 12개 통과. 격리된 실제 Chromium 확장 프로그램에서 설정 저장 및 1분 알람 생성·해제 확인. 공개 API에서는 SOOP 조회를 확인했으며 치지직은 사전 조사 때 정상 응답했으나 최종 재확인 시 시간 초과가 발생했습니다. 실제 계정에서 영상 재생·보상 적립까지 검증한 것은 아닙니다.

조회 시각 보존, 설정 OFF 지연 해소, 설정 간 덮어쓰기 방지, 알림별 목적지 고정, 탭 이동 보호를 적용했습니다. 상세한 재현 조건과 검증 범위는 CHANGES-1.4.1.md를 참고하세요.

## 기록 정렬

최근 수령 날짜부터 표시하며 날짜마다 구분선을 넣습니다. 날짜 안에서는 치지직 → SOOP → 트위치 순서입니다. 수령 날짜는 허브에 처음 처리한 기록 기준이며 쿠폰을 다시 복사해도 유지됩니다.

전체 탭과 플랫폼 탭에도 날짜별 구분선을 표시합니다. 획득 날짜가 없는 보상은 날짜 미상으로 묶습니다. 현재 트위치 조회에는 획득 날짜가 제공되지 않습니다.

## 트위치 날짜 표시 (v1.4.5)

캠페인 이름의 [0917]처럼 월일 표기가 있으면 이를 날짜 분류에 사용합니다. 실제 획득일은 아니며, 기록 탭은 허브 최초 처리일을 유지합니다. 작업 폴더는 E:\Utility\drops hub입니다.
