# Stream Drops Hub v1.5.51

치지직·SOOP·트위치 드롭스를 확인하는 웨일·Chrome 확장프로그램입니다.

## 불러오기

1. 웨일 주소창에 `whale://extensions`를 입력합니다. Chrome에서는 `chrome://extensions`를 사용합니다.
2. 이미 이 폴더의 Stream Drops Hub를 사용 중이라면 확장 프로그램 관리 화면에서 **새로고침**하면 됩니다. 처음 설치하는 경우 다른 설치본을 동시에 켜지 마세요.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. 처음 설치한다면 **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 프로젝트 폴더를 선택합니다. ZIP을 받은 경우 먼저 압축을 풉니다.
5. Stream Drops Hub를 열어 조회 상태를 확인합니다. 트위치 자동 시청·자동 수령은 각각 기본값이 OFF이며 설정에서 따로 켤 수 있습니다.

트위치 자동 수집은 캠페인과 보관함의 서버 진행률·수령 상태로 대상을 선택합니다. 새 캠페인의 진행률이 0이어도 사용자 확인 없이 자동 시청을 시작합니다. 수령 여부를 직접 선택하는 버튼은 없으며, 자동 수령은 기존 **트위치 자동 수령** 설정을 따릅니다. SOOP 자동 수집은 제거했으며, SOOP 보관함·코드 확인·기록과 방송 알림은 유지합니다. 방송 감지의 자동 열기도 치지직에만 적용하며, SOOP 방송은 알림을 직접 눌렀을 때 열립니다.

새 폴더로 등록한 확장프로그램은 기존 설치와 설정·기록 저장소가 분리될 수 있습니다. 같은 설치본을 새로고침하면 기존 설정과 기록을 유지합니다.

트위치에서 허브의 **수령** 버튼 또는 **트위치 자동 수령**으로 성공한 보상은 계정·캠페인·개별 드롭·인스턴스 ID와 수령 시각을 기록합니다. 자동 수집은 이 기록도 완료 판정에 사용하므로 서버가 진행률을 0으로 반환해도 이미 받은 같은 보상을 다시 시청하지 않습니다. 설정의 **오늘 허브 수령**은 한국시간 새벽 5시부터의 성공 기록 수이며, 완료한 캠페인은 다음 날에도 완료로 유지합니다. 이미 수령한 보상이라는 응답만 받은 경우에는 원래 수령 시각을 알 수 없어 오늘 수령 수에 포함하지 않습니다.

기록은 현재 확장 프로그램 설치본에만 저장합니다. 다른 컴퓨터나 트위치 공식 페이지에서 받은 보상은 캠페인별 서버 상태로 확인하며, 예전 기록에 없는 계정·캠페인·드롭 ID를 보상 이름만 보고 추정하지 않습니다. 트위치 수령 성공은 인게임 우편함의 도착 여부까지 확인한 것은 아닙니다.

v1.5.20부터 목록과 자동 수집은 같은 트위치 Inventory 조회를 사용합니다. 설정의 **달성**은 시청 조건을 끝낸 보상 수이며 **수령 완료 / 수령 대기**를 따로 표시합니다. 예전 허브 기록은 공식 응답이 동일한 인스턴스 ID를 제공할 때 계정·캠페인·개별 보상에 연결하고 기존 기록 날짜를 유지합니다. v1.5.21에서는 서버가 인스턴스를 반환하지 않아도 예전 수령 기록의 인스턴스 ID 전체가 현재 조회한 `계정ID#캠페인ID#드롭ID`와 정확히 같으면 연결합니다. 이 식별 형식은 [BetterTTV의 트위치 자동 수령 구현](https://github.com/night/betterttv/blob/master/src/modules/auto_claim/index.js)을 참고했습니다. 다른 계정·캠페인·보상 또는 서버의 다른 인스턴스와는 연결하지 않으며 이름만 보고 완료로 추정하지 않습니다. 정확히 연결한 옛 기록의 오늘 수령 수는 기존 기록 날짜를 기준으로 세며, 알 수 없는 실제 지급 시각을 새로 만들지 않습니다. 표시가 계속 다르면 설정의 **트위치 상태 진단 복사**로 캠페인 상태와 기록의 ID 유무를 확인할 수 있습니다. 진단에는 인증 헤더·쿠키·계정 ID·인스턴스 ID 원문을 포함하지 않습니다.

## 수집 확인

전체·플랫폼·기록 탭의 보상 카드 오른쪽에 한국시간으로 **획득 07:32**처럼 시·분을 표시합니다. 수령·코드 확인 시각 대신 보상의 획득 시각을 사용합니다. 트위치에서 진행률 달성을 확인해 기록한 시각도 같은 형식으로 표시합니다. 날짜만 있거나 획득 시각이 없는 예전 보상은 **시간 미상**으로 표시하며, 시간에 마우스를 올리면 획득 날짜도 확인할 수 있습니다.

**설정 → 수집 상태 및 진단**에 다음 기능이 있습니다.

- **자동 복구 실패 알림**: 기본 꺼짐입니다. 켜면 같은 조회·인증 실패, 재생 복구 실패, 확인된 적립 정체가 서로 다른 확인 3회·2분 이상 지속될 때 브라우저 알림을 보냅니다. 사용자가 탭을 닫아 중지한 경우, 대상 방송·다른 시청 탭 대기 등은 장애로 알리지 않습니다. 같은 문제는 정상 복구 전까지 다시 알리지 않으며 새벽 5시가 지나도 미해결 장애의 알림을 반복하지 않습니다. 브라우저 절전이나 확인 간격이 3분을 넘으면 연속 실패 관찰을 다시 시작합니다.
- **오늘의 수집 요약 · 05시 기준**: 플랫폼별 **오늘 획득 / 수령 대기**를 표시합니다. 수령 버튼을 누른 날짜 대신 획득 날짜를 사용하므로 나중에 수령해도 집계 날짜가 바뀌지 않습니다. 치지직·SOOP은 서버 보상 날짜를 사용하고 SOOP 보상명에 적힌 날짜는 획득 시각으로 추정하지 않습니다. 트위치는 같은 계정·캠페인·보상의 진행률이 미달에서 달성으로 바뀌는 것을 같은 05시 기준 날짜 안에서 확인한 시각을 기록합니다. 처음 조회부터 이미 달성했거나 05시를 걸쳐 달성한 보상은 획득 날짜를 추정하지 않습니다. 기록은 수령·새로고침 후에도 유지하며 숨긴 보상은 제외합니다. 획득 시각이 없는 보상만 있으면 미확인으로 표시합니다. 조회 실패는 이전 조회 기준, 로그아웃·확인 전의 대기 수는 미확인으로 표시합니다.

## 보상 숨기기

이터널리턴 표시 필터는 제거했습니다. 보관함에서 조회한 수령 대기 보상은 게임 종류와 관계없이 표시하며, v1.5.23에서 켜 두었던 필터 설정도 더 이상 적용하지 않습니다.

목록 상단의 **⋯ → 숨길 보상 선택**에서 현재 탭의 보상을 체크하고 **숨기기**를 누릅니다. 선택창에는 보상 아이콘·플랫폼·이름을 표시하며 치지직·SOOP은 한 줄로, 트위치는 캠페인 정보와 함께 표시합니다. 긴 이름과 치지직·SOOP의 캠페인 정보는 항목에 마우스를 올리면 확인할 수 있습니다. 여러 보상을 한 번에 선택할 수 있으며, 취소하면 변경하지 않습니다. 평소 보상 카드에는 숨기기 버튼을 표시하지 않습니다. **설정 → 숨긴 보상**을 펼쳐 **숨김 해제**로 복원할 수 있습니다. 숨김은 새로고침·브라우저 재시작·버전 업데이트·05시 초기화 후에도 유지됩니다. 서버에서 사라지거나 만료된 보상을 복원한다고 다시 수령할 수 있게 되는 것은 아닙니다.

숨긴 보상은 새 보상 알림·트위치 자동 수령에서 제외합니다. 서버 보관함의 보상을 삭제하거나 수령 완료로 기록하지 않으며, 기존 수령 기록과 쿠폰 코드는 그대로 보존합니다. 자동 시청 대상은 기존처럼 이터널리턴 캠페인만 확인합니다.

## 설정 화면

헤더 오른쪽의 톱니바퀴로 설정을 엽니다. 자동 수집, 수집 상태·진단, 보상 알림·수령, 방송 알림, 숨긴 보상, 공식 보관함 순으로 배치했습니다. 긴 사용 안내는 `자동 수집 안내`와 `방송 알림 안내`를 펼치면 볼 수 있습니다. 진단 복사와 최근 자동 수집 동작은 `수집 상태 및 진단`에서 확인합니다.

## 수정한 동작

- 트위치: 선택한 보상 인스턴스 ID로 수령 요청. Twitch 페이지가 실제 GQL 요청에 사용한 `Authorization`·`Client-Integrity`·세션/버전/디바이스 헤더만 읽기 전용으로 캡처해 같은 브라우저 세션의 수령 요청에 재사용. 헤더가 없거나 만료되면 보관함 탭을 열거나 새로고침해 새 헤더를 확보한 뒤 1회 재시도.
- 성공 확인: 성공으로 확인한 보상만 기록하고 목록에서 제거. 알 수 없는 응답·쿠폰 조회 실패는 성공으로 표시하지 않음.
- 자동 수령: OFF일 때 보관함 방문만으로 수령하지 않음. 알림과 수령 상태를 분리하고 실패를 재시도.
- 개별 수령: 각 카드의 수령·코드 확인 버튼으로 하나씩 처리합니다. 전체 수령 버튼은 제거했습니다.
- 쿠폰 기록: 코드 보관됨 / 코드 복사됨 / 인앱 수령 완료 구분. 복사 실패 시에도 이미 확보한 코드는 기록에 보존.
- 기록 저장: 항목별 저장으로 동시 쓰기 유실 방지. 자동 수령도 같은 기록 탭에 반영하며, 만료일이 지난 보상은 기록 목록·개수에서 제외. 자동 수집의 완료 판정에 쓰는 처리 기록과 보관된 코드는 저장소에 유지.
- 설정: 확인 주기 변경을 실제 알람에 적용. 초기 설정 로딩 중에는 입력을 잠금.
- 캐시: 실제 키로 구버전 캐시 삭제. 조회 실패는 정상 0개와 구별하고 마지막 목록에는 최신 조회 필요 표시.
- 날짜: 치지직은 획득 날짜 제한 없이 유효한 보상을 표시. SOOP은 날짜가 확인되면 기존 한국시간 오늘/어제 기준 유지. 날짜만 있는 쿠폰 만료일은 해당 날짜 23:59:59.999까지.
- UI: 인라인 오류 핸들러 제거, 안전한 텍스트 렌더링, 이미지 오류 대체 표시, 가로 넘침 수정.

## 확인한 범위

`npm test`로 보상 수령, 기록 보존, 방송 감지·재생, 트위치 캠페인 판정을 모의 응답 기반으로 확인합니다. 격리된 브라우저 검증은 변경 기록에 범위와 한계를 따로 적었습니다.

실제 사용자 계정의 드롭스를 수령한 검증은 하지 않았습니다. Twitch/치지직/SOOP의 현재 서버 규격·보안 검증에 따른 실계정 수령 성공 여부는 별도 확인이 필요합니다. 트위치 요청이 거부되면 해당 카드를 남기고 보관함에서 확인하도록 안내합니다.

트위치의 캠페인 종료일은 시청 시간 적립 종료일로 취급하며 수령 만료일로 사용하지 않습니다. 공식 보관함에서 시청 조건을 달성했고 아직 수령하지 않은 보상은 캠페인 종료 후에도 표시합니다. 서버의 명시적 수령 기한이 있으면 그 기한만 적용하며, 실제 수령 가능 여부는 서버의 응답으로 확인합니다. 종료 후 임의의 유예 시간을 계산하지 않습니다.

치지직은 정상 재생 중 보상별 서버 진행과 새 획득 여부를 확인합니다. 진행이 10분간 그대로면 2분 동안 재확인하고, 여전히 정체 상태이며 같은 캠페인의 대체 방송이 있을 때 기존 자동 시청 탭으로 전환합니다. 다른 방송이 없으면 현재 방송을 유지합니다. 진행 정보가 없거나 조회가 실패했거나 재생 복구 중이면 정체를 확정하지 않습니다. 브라우저 절전 등으로 확인 간격이 3분을 넘으면 관찰을 다시 시작합니다.

설정의 **최근 자동 수집 동작**을 펼치면 치지직·트위치의 방송 열기·전환, 재생과 복구 상태, 적립 증가·새 획득, 조회 실패·정상화, 트위치 수령 결과를 최근 8개까지 확인할 수 있습니다. 최근 7일의 동작을 최대 100개 보관하며 새벽 5시 초기화에도 최근 동작 기록은 유지합니다. **전체 자동 수집 진단 복사**에는 두 플랫폼의 상태, 확인 시각, 탭 소유·음소거 상태, 보상별 캠페인 집계와 최근 동작을 포함합니다. 쿠키·인증 헤더·계정 ID·방송 주소·인스턴스 ID 원문과 서버 오류 원문은 제외합니다. 기존 트위치 전용 진단 버튼도 유지합니다.

치지직 자동 수집이 켜져 있으면 약 1분마다 캠페인 목록도 갱신해 설정과 공유합니다. 카테고리 목록에서 빠진 캠페인은 드롭스 표시 방송의 캠페인 ID로 상세 정보를 확인해 보완합니다. **모든 캠페인 순차 수집**에서는 새 캠페인을 자동 포함하며, 특정 캠페인을 선택한 경우 선택을 유지합니다. 일부 캠페인 조회가 실패하면 정상 캠페인은 계속 진행하고 실패한 항목은 다음 주기에 재시도합니다. 확인하지 못한 항목을 전체 완료로 처리하지 않습니다.

## 자동 수집 진행률

직접 연 치지직 방송 탭도 서버에서 확인한 드롭스 방송 채널과 대조합니다. 해당 캠페인을 대표 이름과 상세 목록 맨 위에 표시하고 **열린 방송**으로 구분합니다. 여러 캠페인의 방송 탭을 열었다면 활성 탭에 해당하는 캠페인을 우선합니다. 허브의 자동 수집 탭은 **자동 수집 대상**으로 따로 표시합니다. 열린 탭을 재생 중이거나 적립 중이라고 추정하지 않으며, 실제 %는 서버 진행 정보를 사용합니다. 자동 시청 순서·재생과 개별 수령 동작은 바뀌지 않습니다.

헤더의 **진행률** 버튼을 누르면 치지직·트위치의 **다음 보상 진행률**, **현재/필요 시청 시간**, **달성 보상 수**를 별도 창에서 확인합니다. 요약을 누르면 캠페인별 보상 진행률과 수령 대기·수령 완료 상태를 펼쳐 볼 수 있습니다. 어느 탭에서든 같은 버튼으로 확인하며, 목록 본문에는 진행률 요약을 표시하지 않습니다. **닫기**, **Esc** 또는 창 바깥 클릭으로 닫습니다. 자동 수집을 모두 끈 경우 설정 안내를 표시합니다.

기존 약 1분 주기의 서버 조회 결과를 사용합니다. 여러 보상의 시간을 합쳐 캠페인 전체 %로 계산하거나 방송을 켜둔 시간으로 추정하지 않습니다. **100%는 시청 조건 달성**이며 수령 완료와 구분합니다. 조회 실패·3분 이상 지난 조회·05시 초기화 전 데이터는 **이전 조회 기준**을 표시하고 마지막 진행률을 유지합니다. 확인하지 못한 시청 시간은 0%로 바꾸지 않고 **확인 대기**로 표시합니다.

## 이터널리턴 방송 감지 (v1.4.0)

설정 → 이터널리턴 드롭스 방송에서 **방송 감지 및 알림**을 켜세요. 치지직·SOOP의 해당 카테고리에서 실제 드롭스 표시가 있는 방송을 약 1분마다 확인합니다. 켜는 시점에 이미 방송 중인 채널도 대상입니다. 치지직 알림은 캠페인별로 중복을 막으며 마지막 감지부터 30일간 기록을 유지합니다. SOOP은 현재 방송 목록에 캠페인 ID가 없어 한국시간 기준 같은 카테고리에서 하루 한 번 알립니다.

**자동으로 방송 열기**도 켜면 시청자 수가 많은 치지직 대상 방송 한 개를 백그라운드 탭으로 엽니다. SOOP은 방송 알림만 제공하며, 알림을 직접 눌러 방송을 열 수 있습니다. 이미 대상 방송을 열어 두었다면 추가 탭을 만들지 않습니다. 두 설정의 기본값은 꺼짐입니다. 감지를 끄면 자동 열기도 중단되며 기존 탭은 닫지 않습니다.

브라우저가 실행 중이어야 하며 절전 상태에서는 확인이 늦어질 수 있습니다. 방송 페이지를 여는 기능으로, 자동 재생이나 드롭스 시청 시간 적립을 보장하지 않습니다. 알림은 운영체제의 브라우저 알림 허용 상태에 영향을 받습니다. 조회 실패는 설정에 표시하며 다음 주기에 재시도합니다.

검증: 기존 회귀 검사 28개와 방송 감지 검사 12개 통과. 격리된 실제 Chromium 확장 프로그램에서 설정 저장 및 1분 알람 생성·해제 확인. 공개 API에서는 SOOP 조회를 확인했으며 치지직은 사전 조사 때 정상 응답했으나 최종 재확인 시 시간 초과가 발생했습니다. 실제 계정에서 영상 재생·보상 적립까지 검증한 것은 아닙니다.

## 기록 정렬

최근 수령 날짜부터 표시하며 날짜마다 구분선을 넣습니다. 날짜 안에서는 치지직 → SOOP → 트위치 순서입니다. 수령 날짜는 허브에 처음 처리한 기록 기준이며 쿠폰을 다시 복사해도 유지됩니다.

만료일이 지난 기록은 목록과 기록 개수에서 자동으로 제외합니다. 날짜만 있는 만료일은 한국시간 그날 23:59:59.999까지 표시하고, 만료일이 없거나 해석할 수 없으면 표시를 유지합니다. 팝업을 열어 둔 상태에서도 만료 시각이 지나면 갱신합니다. 수령 완료 판정에 필요한 내부 기록과 쿠폰은 유지하므로, 이미 받은 보상을 다시 시청·수령하지 않습니다.

전체 탭과 플랫폼 탭에도 날짜별 구분선을 표시합니다. 획득 날짜가 없는 보상은 날짜 미상으로 묶습니다. 트위치는 실제 획득 날짜를 제공하지 않으므로 제목의 MMDD, 개별 드롭 시작일, 캠페인 시작일 순으로 표시용 날짜를 정합니다.

## 트위치 날짜 표시 (v1.4.5)

캠페인 이름의 [0917]처럼 월일 표기가 있으면 이를 우선 사용합니다. 표기가 없으면 트위치 Inventory의 개별 드롭 시작일(`timeBasedDrops.startAt`), 없으면 캠페인 시작일(`startAt`)을 한국시간 날짜로 사용합니다. 실제 획득일은 아니며, 기록 탭은 허브 최초 처리일을 유지합니다.


## 이터널리턴 자동 수집 (v1.5.0)

확장 프로그램 관리 화면에서 이 폴더의 확장 프로그램을 새로고침한 뒤 설정의 **이터널리턴 자동 수집**을 사용합니다. 새 재생 제어 권한을 Chrome이 요청하면 확인해 주세요. 두 플랫폼의 토글은 기본 OFF입니다.

1. 설정을 열면 치지직 캠페인 목록을 자동 확인합니다. **캠페인 목록 새로고침**으로 즉시 다시 확인할 수도 있습니다.
2. 치지직에서 특정 캠페인(예: S12 미드시즌 / 로드 투 마스터즈)을 선택하거나 **모든 캠페인 순차 수집**을 선택합니다.
3. **치지직 자동 수집** 또는 **트위치 자동 수집**을 켭니다. 이 토글은 방송 시청과 전환을 수행합니다. 치지직·SOOP 쿠폰 코드 확인·복사는 직접 진행합니다.
4. 자동으로 열린 탭에서 로그인·게임 계정 연결 및 드롭스 참여 설정을 확인합니다. 치지직은 일반 방송을 다른 탭에서 보고 있어도 별도의 음소거 수집 탭을 열고 유지합니다. 트위치는 다른 트위치 방송 탭이 있으면 중복 시청 방지를 위해 대기합니다. 재생이 실패하면 제한 횟수 재시도하며, 계속 실패하면 상태의 원인과 로그인·성인 인증 상태를 확인해 주세요.

플랫폼별 한 탭을 잠깐 활성화하고 브라우저 탭을 음소거한 상태에서 재생을 시작합니다. 치지직·트위치 영상 요소는 음소거를 해제합니다. 실제 영상 시간이 증가하면 이전 탭으로 돌아옵니다. 자동 수집기가 소유한 탭은 자동 폐기를 막고, 폐기된 경우 재생을 복구합니다. 사용자가 다른 탭으로 이동하면 포커스를 되돌리지 않습니다. 약 1분마다 대상 방송·캠페인·서버 진행 정보를 확인합니다. 방송이 끝나거나 대상에서 빠지면 현재 캠페인의 다른 방송으로 전환합니다. 치지직 전체 캠페인 모드에서는 완료된 캠페인을 건너뛰고 다음 캠페인을 시청합니다. 현재 캠페인에 방송이 없으면 다른 미완료 캠페인부터 진행하고 다시 확인합니다. 보상 소진·기간 종료도 시청 대상에서 제외합니다.

치지직은 현재 캠페인의 보상 ID와 계정의 달성 목록을 대조합니다. SOOP 자동 시청은 제공하지 않습니다. 치지직·SOOP 쿠폰을 자동으로 처리하거나 기록 탭으로 옮기지 않습니다. 목록에서 직접 코드 확인·복사를 한 뒤 게임에 입력해 주세요. 기존 자동 수령 설정은 트위치에만 적용됩니다.

토글 OFF 시 자동 생성한 방송 탭만 닫습니다. 자동 생성 탭을 직접 닫거나 다른 페이지로 이동하면 임의로 다시 열지 않고 일시 중지합니다. 재개하려면 토글을 껐다 켜세요. 브라우저 재시작 후 이전 탭을 찾지 못한 경우에도 같은 방법으로 재개할 수 있습니다. 기존 방송 감지의 자동 열기는 자동 수집이 켜진 플랫폼에서 중복 동작하지 않습니다.

브라우저가 실행 중이어야 합니다. 영상 재생 확인과 서버 적립 확인은 별개이며, 적립이 늘지 않으면 상태에 안내합니다. 로그인, 성인 인증과 계정 연결은 직접 진행해야 합니다. 치지직의 브라우저 자동재생 차단은 재생 권한으로 복구를 시도하며, 회사 정책 등으로 권한을 사용할 수 없으면 실패 상태를 표시합니다. 다른 기기에서의 동시 시청은 탐지할 수 없습니다.

v1.5.0 검증: 회귀 39개, 방송 감지 20개, 자동 수집 19개 통과. 실제 확장 프로그램을 격리된 Chromium에 로드하고 모의 API/테스트 영상으로 재생 시간 증가, 같은 탭 방송 전환, 캠페인 전환, 쿠폰 저장, OFF 탭 정리를 확인했습니다. 공개 치지직 캠페인 목록과 상세 응답은 실제 조회했습니다. 로그인한 실제 계정의 드롭스 적립·실수령 완료는 검증하지 않았습니다.

한국 시간 05:00 이후 첫 확인(정상 실행 시 약 1분 이내)에 방송 알림 중복 방지와 자동 수집의 일시 중지·실패·쿨다운 상태를 초기화합니다. 브라우저가 꺼져 있으면 다음 실행 때 반영합니다. 켜 둔 기능만 동작하며 기존 자동 시청 탭은 재사용합니다. 설정, 받은 보상과 쿠폰 기록 및 서버 진행도는 유지됩니다.

## 1.5.4 — 화면이 꺼진 동안 새 방송 재생 시작

새 방송의 탭은 처음부터 음소거합니다. SOOP 영상 요소는 음소거하고, 치지직·트위치 영상 요소는 재생을 시작한 뒤 음소거를 해제합니다. 재생 실패는 최대 8회 짧게 재시도하며, 오류 종류와 영상 상태를 확장 프로그램 저장소의 `collectorState.<platform>.diagnostic`에 민감 정보 없이 기록합니다. 영상 시간이 증가한 경우만 재생 성공으로 표시합니다. 이미 정상 재생 중인 방송은 주기적으로 새로고침하지 않습니다.

모의 CHZZK·SOOP URL의 일시정지 영상으로 격리 Chromium 재생 시작을 확인했습니다. 실제 확장 프로그램의 모의 CHZZK 시나리오에서도 재생 시작, 같은 탭 방송 전환과 캠페인 전환을 확인했습니다. 전체 검사 92개가 통과했습니다. 실제 사이트 계정의 플레이어 구조, 모니터 물리 OFF 및 드롭스 적립은 현장 확인이 필요합니다.

## 1.5.5 — SOOP 실제 방송 재생 수정

SOOP는 처음 표시하는 짧은 안내 영상과 실제 라이브 영상이 다릅니다. 자동 수집기가 방송 화면의 재생 버튼을 눌러 라이브 영상이 재생되는지 확인하도록 수정했습니다. 방송 탭은 계속 음소거합니다. 페이지가 재로딩 중 잠깐 빈 주소로 표시될 때는 사용자 이동으로 판단하지 않고 다음 확인을 기다립니다.

공개 SOOP 방송에서 실제 확장 프로그램이 라이브 영상 재생을 시작하고 영상 시간이 증가하는 것을 격리 Chromium에서 확인했습니다. 로그인한 계정의 드롭스 적립과 모니터를 끈 밤샘 상태는 사용 환경에서 확인이 필요합니다. `chrome://extensions`에서 이 확장 프로그램을 **새로고침**하면 수정 사항이 적용됩니다.

## 1.5.6 — SOOP 방송 탭 반복 전환 방지

이미 재생을 시작한 SOOP 방송은 주기적인 재생 검사에 일시적으로 실패해도 먼저 백그라운드에서 복구를 시도합니다. 이때 보고 있던 탭을 SOOP 방송 탭으로 전환하지 않습니다. 새 방송을 처음 열거나 방송이 바뀔 때는 재생 시작을 위해 잠깐 활성화할 수 있습니다. 수정본을 불러온 뒤 확장 프로그램 관리 화면에서 새로고침해 적용하세요.

## 1.5.7 — SOOP 방송 주소 및 팝업 초기화 안정화

SOOP 방송의 `.com` / `.co.kr` 도메인 전환을 같은 방송으로 인식합니다. 팝업 초기화에 일시적인 오류가 나도 설정 컨트롤의 잠금이 풀립니다. 확장 프로그램 관리 화면에서 새로고침해 적용하세요.

## 1.5.8 — 작업 결과 알림 한 개로 갱신

팝업에서 코드 확인·수령·복사 결과가 연속으로 나오면 기존 알림을 새 내용으로 바꾸고 표시 시간을 다시 시작합니다. 알림이 여러 개 쌓여 보상 목록을 가리지 않습니다.

## 1.5.9 — 치지직 재생 시작 및 백그라운드 복구

치지직 방송 탭에서 재생 버튼이 아직 눌리지 않아 영상 요소가 없는 경우에도 플레이어의 재생 버튼을 눌러 시작합니다. 광고 영상은 라이브 재생 성공으로 취급하지 않습니다. 원래 보던 탭으로 돌아온 뒤 영상이 멈추면 먼저 백그라운드에서 재생을 복구합니다. v1.5.18부터 이 복구가 실패할 때는 제한적으로 탭·창을 활성화해 재시도합니다. 이후 주기적인 확인에서도 같은 방식으로 복구합니다.

업데이트 후 `chrome://extensions`에서 Stream Drops Hub를 새로고침해 적용하세요. 격리 Chromium에서 재생 버튼과 탭 전환 뒤의 재생 복구를 확인했지만, 로그인한 치지직 계정의 실제 드롭스 적립은 사용자 환경에서 확인해야 합니다.

## 1.5.10 — 자동 수집 상태 목록 간소화

설정의 자동 수집 상태에는 진행 중인 캠페인만 표시합니다. 시청 조건을 달성했거나 기간이 끝난 캠페인의 긴 목록은 숨깁니다. 방송 시청과 드롭스 기록 데이터는 그대로 유지됩니다.

## 1.5.11 — 자동 수집 및 SOOP 날짜 판별 안정화

현재 캠페인의 모든 방송이 잠시 재시도 대기 중이면 다른 진행 가능한 캠페인으로 전환합니다. SOOP 보상명에 이벤트 기간과 대괄호 날짜가 함께 있으면 보상 날짜를 우선 사용하고, `100%` 진행률을 완료로 읽습니다. 치지직 잔여 수량이 문자열 `0`이면 소진으로 처리하며, 수집 주기가 예외로 끝나더라도 뒤따른 설정 변경을 다시 반영합니다.

## 1.5.12 — 트위치 실제 방송 자동 수집

설정의 **트위치 자동 수집**을 켜면 브라우저가 실행 중일 때 계정의 진행 가능한 이터널리턴 캠페인을 확인합니다. 드롭스 대상 Twitch 채널을 확장 프로그램 소유 탭으로 열어 음소거한 실제 영상을 재생하고, 약 1분마다 방송과 서버 시청 진행을 확인합니다. 방송이 끝나거나 진행이 10분 넘게 늘지 않으면 다른 대상 방송으로 전환을 시도합니다. 트위치에 직접 열어 둔 다른 방송 탭이 있으면 중복 시청을 피하기 위해 대기합니다.

시청 조건을 달성한 보상의 수령은 기존 **트위치 자동 수령** 토글이 담당합니다. 수령 대기 보상이 있어도 같은 캠페인에 시청 시간이 부족한 다른 보상이 있으면 방송을 계속 재생합니다. 예를 들어 1·2·3시간 보상은 첫 보상을 수령하지 않아도 남은 보상의 시청 시간을 채우며, 모든 보상의 시청 조건을 달성하면 확장 프로그램이 연 방송 탭을 닫고 수령을 기다립니다. 다른 시청 가능한 캠페인이 있으면 이어서 진행합니다. 게임 계정이 아직 연결되지 않아도 시청을 진행하며, 실제 게임에 보상을 받으려면 연결하도록 설정 상태에 안내합니다. 트위치 자동 수집의 기본값은 OFF이며, 켠 뒤 탭을 직접 닫거나 다른 페이지로 이동하면 토글을 껐다 켜서 재개할 수 있습니다. 로그인한 실제 계정에서 서버 적립과 캠페인별 수령이 되는지는 사용 환경에서 확인해야 합니다.

## 1.5.15 — 트위치 캠페인 조회 오류 복구

트위치의 기본 드롭스 보관함 조회와 지급 기록 조회를 분리했습니다. 지급 기록은 캠페인 수령 여부가 불확실할 때 보조 근거로만 사용하며, 합산 지급 카드만으로 특정 캠페인의 완료를 확정하지 않습니다. 지급 기록 조회가 거부되고 서버 시청 진행도도 0분이라 수령 여부를 가릴 수 없으면 자동 시청을 보류하고 설정에서 수동 판정을 선택할 수 있습니다.

## 1.5.14 — 다른 기기 수령 상태 반영

자동 시청 탭을 직접 닫거나 이동해 시청이 일시 중지된 상태에서도 각 플랫폼의 캠페인·수령 상태를 약 1분마다 다시 조회합니다. 같은 계정의 공식 보관함이 캠페인별 완료 상태를 제공하면 다른 기기에서 받은 보상도 반영합니다. 합산 보상 카드만 남은 경우에는 완료를 추정하지 않고 확인을 보류합니다. 일시 중지된 시청은 자동으로 재개되지 않습니다. 조회 실패 또는 오래된 결과의 달성 수치는 설정 화면에서 숨기고 재확인 상태를 표시합니다.

## 1.5.13 — 치지직·트위치 플레이어 음소거 해제

치지직과 트위치 자동 시청은 **브라우저 탭만 음소거**하고 사이트의 영상 요소는 음소거 해제하며 볼륨이 0이면 복원합니다. Chrome이 소리 있는 자동재생을 차단할 때만 영상 요소를 잠깐 음소거해 재생을 시작한 뒤 즉시 음소거 해제를 시도합니다. 음소거 해제 후 재생이 멈추면 성공으로 표시하지 않고 재시도 상태를 기록합니다. SOOP은 이미 적립을 확인한 기존 재생 방식을 유지합니다.

모의 테스트 128개와 격리된 Chrome의 합성 영상에서 플레이어 음소거 해제 및 영상 시간 증가를 확인했습니다. 격리된 Chrome의 확장 서비스워커가 실행되지 않아 브라우저 통합 테스트에서 탭 음소거 상태는 확인하지 못했으며, 해당 API 호출은 자동 테스트로 검증했습니다. 실제 로그인 계정의 드롭스 적립은 아직 검증하지 않았습니다.

## 1.5.18 — 자동 수집 방식 정리와 치지직 재생 복구

트위치의 캠페인별 수동 수령 판정과 확인 대기를 제거했습니다. 새 캠페인이 0분이어도 자동 시청을 시작하며, 수령은 기존 트위치 자동 수령 설정을 따릅니다. SOOP 자동 수집 토글·진행 조회·재생 제어를 제거했습니다. 업데이트하면 예전 자동 수집기가 만든 SOOP 방송 탭만 정리하며, 사용자가 이동한 탭과 SOOP 코드·기록은 유지합니다.

치지직은 백그라운드 재생 재시도가 실패하면 확장 프로그램 소유 탭과 필요한 경우 브라우저 창을 잠깐 활성화해 재생을 복구합니다. 오류·정지·플레이어 미감지 상태에서는 페이지도 다시 로딩합니다. 이 복구는 같은 세션에서 방송이 바뀌어도 10분에 한 번으로 제한합니다. 재생이 정상인 방송은 활성화하거나 다시 로딩하지 않습니다. 원래 탭과 최소화 상태를 복원한 뒤 다시 재생 상태를 확인하며, 도중에 사용자가 탭을 바꾸면 이전 탭으로 돌려놓지 않습니다. 영상과 제어 버튼은 열린 shadow root 내부도 탐색합니다.

모의 회귀 검사 149개와 격리 Chromium의 합성 영상으로 재생 시작·일시 정지 복구·영상 시간 증가를 확인했습니다. 실제 확장 프로그램을 새 프로필에 로드해 `AutoplayUnmutePaused` 차단을 재현한 뒤 브라우저 재생 권한으로 복구했고, 탭 음소거 ON·플레이어 음소거 OFF·영상 시간 증가·팝업 오류 0개를 확인했습니다. 실제 회사 컴퓨터의 새벽 5시 실행, 로그인한 치지직 계정의 적립과 물리 모니터 OFF 상태는 이 검사에 포함되지 않습니다. 회사 컴퓨터에서도 확장 프로그램 파일을 업데이트하고 `chrome://extensions`에서 새로고침해야 적용됩니다.

치지직의 일반 재생이 `NotAllowedError` 또는 `AutoplayUnmutePaused`로 차단되면 `debugger` 권한으로 확장 수집기가 만든 치지직 방송 탭에만 잠깐 연결합니다. 서버 수집 상태에 저장된 소유권·정확한 방송 주소·설정·활성 상태를 확인한 뒤 `Runtime.evaluate`의 `userGesture`로 기존 재생 함수만 실행하고 연결을 해제합니다. 트위치나 직접 연 탭에는 적용하지 않습니다. 이 권한 자체는 브라우저 탭 검사·제어가 가능한 강한 권한이며 Chrome 안내가 잠깐 표시될 수 있습니다. 업데이트 후 추가 권한 확인이 표시되면 확인해 주세요. 공식 API: [Chrome debugger](https://developer.chrome.com/docs/extensions/reference/api/debugger).
