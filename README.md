# Stream Drops Hub 수정본 v1.5.1

원본과 별도 폴더에서 작업한 Chrome 확장프로그램입니다.

## 불러오기

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 기존 Stream Drops Hub가 켜져 있다면 꺼 두세요. 두 확장프로그램이 동시에 수령을 시도하지 않도록 하기 위한 절차입니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `stream-drops-hub-fixed` 폴더를 선택합니다. ZIP을 받은 경우 먼저 압축을 풉니다.
5. **Stream Drops Hub - 수정본**을 열어 조회 상태를 확인합니다. 트위치 자동 수령 기본값은 OFF이며 설정에서 켤 수 있습니다.

새 폴더로 등록한 확장프로그램은 기존 설치와 설정·기록 저장소가 분리될 수 있습니다. 기존 확장프로그램의 기록은 삭제하지 않았습니다. 같은 확장 ID의 버전 업데이트인 경우에는 코드에 포함된 마이그레이션이 기존 쿠폰 기록을 보존합니다.

## 수정한 동작

- 트위치: 선택한 보상 인스턴스 ID로 수령 요청. Twitch 페이지가 실제 GQL 요청에 사용한 `Authorization`·`Client-Integrity`·세션/버전/디바이스 헤더만 읽기 전용으로 캡처해 같은 브라우저 세션의 수령 요청에 재사용. 헤더가 없거나 만료되면 보관함 탭을 열거나 새로고침해 새 헤더를 확보한 뒤 1회 재시도.
- 성공 확인: 성공으로 확인한 보상만 기록하고 목록에서 제거. 알 수 없는 응답·쿠폰 조회 실패는 성공으로 표시하지 않음.
- 자동 수령: OFF일 때 보관함 방문만으로 수령하지 않음. 알림과 수령 상태를 분리하고 실패를 재시도.
- 전체 수령: 남은 작업 저장. 팝업을 닫아도 계속 처리하며 브라우저 재시작 후 남은 작업을 재개. 실패한 항목은 재시도 가능.
- 쿠폰 기록: 코드 보관됨 / 코드 복사됨 / 인앱 수령 완료 구분. 복사 실패 시에도 이미 확보한 코드는 기록에 보존.
- 기록 저장: 항목별 저장으로 동시 쓰기 유실 방지. 자동 수령도 같은 기록 탭에 반영.
- 설정: 확인 주기 변경을 실제 알람에 적용. 초기 설정 로딩 중에는 입력을 잠금.
- 캐시: 실제 키로 구버전 캐시 삭제. 조회 실패는 정상 0개와 구별하고 마지막 목록에는 최신 조회 필요 표시.
- 날짜: 치지직은 획득 날짜 제한 없이 유효한 보상을 표시. SOOP은 날짜가 확인되면 기존 한국시간 오늘/어제 기준 유지. 날짜만 있는 쿠폰 만료일은 해당 날짜 23:59:59.999까지.
- UI: 인라인 오류 핸들러 제거, 안전한 텍스트 렌더링, 이미지 오류 대체 표시, 가로 넘침 수정.

## 확인한 범위

- 원본 17개 파일: 작업 전후 SHA-256 및 파일 수 일치.
- 회귀 테스트 28개 통과: 쿠폰 조회 실패, 수령 실패 재시도, 자동 수령 설정 변경, 동시 기록, 날짜 경계, 캐시 마이그레이션, 설정 알람, 전체 수령 재개, 발신자 검증, 응답 본문 타임아웃 등.
- 임시 Chromium UI 테스트: 탭 전환, 설정, 클립보드 복사, 실패한 쿠폰 유지, 정상 쿠폰 기록, HTML 텍스트 이스케이프, 레이아웃 확인.
- 별도 Chromium 프로필에 실제 확장프로그램 로드: 서비스워커, 실제 메시지 왕복, 5분 알람 반영, 팝업을 닫은 후 모의 쿠폰의 백그라운드 기록 확인.

실제 사용자 계정의 드롭스를 수령한 검증은 하지 않았습니다. Twitch/치지직/SOOP의 현재 서버 규격·보안 검증에 따른 실계정 수령 성공 여부는 별도 확인이 필요합니다. 트위치 요청이 거부되면 해당 카드를 남기고 보관함에서 확인하도록 안내합니다.

트위치 캠페인에 임의의 24시간 유예를 더하지 않습니다. 서버의 명시적 수령 기한이 있으면 그것을, 없으면 캠페인 종료일을 사용하므로 실제 서버의 별도 유예 규칙까지 검증한 것은 아닙니다.

## 이터널리턴 방송 감지 (v1.4.0)

설정 → 이터널리턴 드롭스 방송에서 **방송 감지 및 알림**을 켜세요. 치지직·SOOP의 해당 카테고리에서 실제 드롭스 표시가 있는 방송을 약 1분마다 확인합니다. 켜는 시점에 이미 방송 중인 채널도 대상입니다. 치지직 알림은 캠페인별로 중복을 막으며 마지막 감지부터 30일간 기록을 유지합니다. SOOP은 현재 방송 목록에 캠페인 ID가 없어 한국시간 기준 같은 카테고리에서 하루 한 번 알립니다.

**자동으로 방송 열기**도 켜면 플랫폼별 시청자 수가 많은 대상 방송 한 개를 백그라운드 탭으로 엽니다. 이미 대상 방송을 열어 두었다면 추가 탭을 만들지 않습니다. 두 설정의 기본값은 꺼짐입니다. 감지를 끄면 자동 열기도 중단되며 기존 탭은 닫지 않습니다.

브라우저가 실행 중이어야 하며 절전 상태에서는 확인이 늦어질 수 있습니다. 방송 페이지를 여는 기능으로, 자동 재생이나 드롭스 시청 시간 적립을 보장하지 않습니다. 알림은 운영체제의 브라우저 알림 허용 상태에 영향을 받습니다. 조회 실패는 설정에 표시하며 다음 주기에 재시도합니다.

검증: 기존 회귀 검사 28개와 방송 감지 검사 12개 통과. 격리된 실제 Chromium 확장 프로그램에서 설정 저장 및 1분 알람 생성·해제 확인. 공개 API에서는 SOOP 조회를 확인했으며 치지직은 사전 조사 때 정상 응답했으나 최종 재확인 시 시간 초과가 발생했습니다. 실제 계정에서 영상 재생·보상 적립까지 검증한 것은 아닙니다.

## 기록 정렬

최근 수령 날짜부터 표시하며 날짜마다 구분선을 넣습니다. 날짜 안에서는 치지직 → SOOP → 트위치 순서입니다. 수령 날짜는 허브에 처음 처리한 기록 기준이며 쿠폰을 다시 복사해도 유지됩니다.

전체 탭과 플랫폼 탭에도 날짜별 구분선을 표시합니다. 획득 날짜가 없는 보상은 날짜 미상으로 묶습니다. 트위치는 실제 획득 날짜를 제공하지 않으므로 제목의 MMDD, 개별 드롭 시작일, 캠페인 시작일 순으로 표시용 날짜를 정합니다.

## 트위치 날짜 표시 (v1.4.5)

캠페인 이름의 [0917]처럼 월일 표기가 있으면 이를 우선 사용합니다. 표기가 없으면 트위치 Inventory의 개별 드롭 시작일(`timeBasedDrops.startAt`), 없으면 캠페인 시작일(`startAt`)을 한국시간 날짜로 사용합니다. 실제 획득일은 아니며, 기록 탭은 허브 최초 처리일을 유지합니다.


## 이터널리턴 자동 수집 (v1.5.0)

확장 프로그램 관리 화면에서 이 폴더의 확장 프로그램을 새로고침한 뒤 설정의 **이터널리턴 자동 수집**을 사용합니다. 새 재생 제어 권한을 Chrome이 요청하면 확인해 주세요. 두 플랫폼의 토글은 기본 OFF입니다.

1. **캠페인 목록 새로고침**을 누릅니다.
2. 치지직에서 특정 캠페인(예: S12 미드시즌 / 로드 투 마스터즈)을 선택하거나 **모든 캠페인 순차 수집**을 선택합니다.
3. **치지직 자동 수집**, **SOOP 자동 수집** 중 원하는 플랫폼을 켭니다. 이 토글은 방송 시청과 전환만 수행합니다. 쿠폰 코드 확인·복사는 직접 진행합니다.
4. 다른 방송 탭은 닫고, 자동으로 열린 탭에서 로그인·게임 계정 연결 및 드롭스 참여 설정을 확인합니다. 음소거 재생도 실패하면 자동으로 제한 횟수 재시도합니다. 계속 실패하면 상태의 원인을 확인하고 로그인·성인 인증 상태를 점검해 주세요.

플랫폼별 한 탭을 잠깐 활성화하고 브라우저 탭과 영상 요소를 모두 음소거한 상태에서 재생을 시작합니다. 실제 영상 시간이 증가하면 이전 탭으로 돌아옵니다. 자동 수집기가 소유한 탭은 자동 폐기를 막고, 폐기된 경우 재생을 복구합니다. 사용자가 다른 탭으로 이동하면 포커스를 되돌리지 않습니다. 약 1분마다 대상 방송·캠페인·서버 진행 정보를 확인합니다. 방송이 끝나거나 대상에서 빠지면 현재 캠페인의 다른 방송으로 전환합니다. 치지직 전체 캠페인 모드에서는 완료된 캠페인을 건너뛰고 다음 캠페인을 시청합니다. 현재 캠페인에 방송이 없으면 다른 미완료 캠페인부터 진행하고 다시 확인합니다. 보상 소진·기간 종료도 시청 대상에서 제외합니다.

치지직은 현재 캠페인의 보상 ID와 계정의 달성 목록을 대조합니다. SOOP은 이터널리턴 미션의 서버 진행률을 사용하며, 아직 참여 미션이 없으면 대상 방송에 들어가 다음 확인에서 미션 등록 여부를 확인합니다. 이전 날짜에 끝난 미션이 새 미션 참여를 막지 않습니다. 치지직·SOOP 쿠폰을 자동으로 처리하거나 기록 탭으로 옮기지 않습니다. 목록에서 직접 코드 확인·복사를 한 뒤 게임에 입력해 주세요. 기존 자동 수령 설정은 트위치에만 적용됩니다.

토글 OFF 시 자동 생성한 방송 탭만 닫습니다. 자동 생성 탭을 직접 닫거나 다른 페이지로 이동하면 임의로 다시 열지 않고 일시 중지합니다. 재개하려면 토글을 껐다 켜세요. 브라우저 재시작 후 이전 탭을 찾지 못한 경우에도 같은 방법으로 재개할 수 있습니다. 기존 방송 감지의 자동 열기는 자동 수집이 켜진 플랫폼에서 중복 동작하지 않습니다.

브라우저가 실행 중이어야 합니다. 영상 재생 확인과 서버 적립 확인은 별개이며, 적립이 늘지 않으면 상태에 안내합니다. 로그인, 성인 인증, 계정 연결, 자동 재생 제한은 자동으로 우회하지 않습니다. 다른 기기에서의 동시 시청은 탐지할 수 없습니다.

v1.5.0 검증: 회귀 39개, 방송 감지 20개, 자동 수집 19개 통과. 실제 확장 프로그램을 격리된 Chromium에 로드하고 모의 API/테스트 영상으로 재생 시간 증가, 같은 탭 방송 전환, 캠페인 전환, 쿠폰 저장, OFF 탭 정리를 확인했습니다. 공개 치지직 캠페인 목록과 상세 응답은 실제 조회했습니다. 로그인한 실제 계정의 드롭스 적립·실수령 완료는 검증하지 않았습니다.

## v1.5.1 변경

치지직·SOOP 자동 쿠폰 처리를 제거했습니다. 캠페인 진행 조회, 자동 시청과 방송 전환은 유지합니다. 자동 수령은 트위치에만 적용하며 치지직·SOOP의 수동 코드 확인·복사와 사용자가 누른 전체 수령은 유지합니다. 검사 79개 통과.

## 1.5.3 — 새벽 5시 기준

한국 시간 05:00 이후 첫 확인(정상 실행 시 약 1분 이내)에 방송 알림 중복 방지와 자동 수집의 일시 중지·실패·쿨다운 상태를 초기화합니다. 브라우저가 꺼져 있으면 다음 실행 때 반영합니다. 켜 둔 기능만 동작하며 기존 자동 시청 탭은 재사용합니다. 설정, 받은 보상과 쿠폰 기록 및 서버 진행도는 유지됩니다.

## 1.5.4 — 화면이 꺼진 동안 새 방송 재생 시작

새 CHZZK·SOOP 방송은 영상 요소를 음소거한 뒤 `play()`를 호출합니다. 탭도 처음부터 음소거 상태를 유지합니다. 재생 실패는 최대 8회 짧게 재시도하며, 오류 종류와 영상 상태를 확장 프로그램 저장소의 `collectorState.<platform>.diagnostic`에 민감 정보 없이 기록합니다. 영상 시간이 증가한 경우만 재생 성공으로 표시합니다. 이미 정상 재생 중인 방송은 주기적으로 새로고침하지 않습니다.

모의 CHZZK·SOOP URL의 일시정지 영상으로 격리 Chromium 재생 시작을 확인했습니다. 실제 확장 프로그램의 모의 CHZZK 시나리오에서도 재생 시작, 같은 탭 방송 전환과 캠페인 전환을 확인했습니다. 전체 검사 92개가 통과했습니다. 실제 사이트 계정의 플레이어 구조, 모니터 물리 OFF 및 드롭스 적립은 현장 확인이 필요합니다.

## 1.5.5 — SOOP 실제 방송 재생 수정

SOOP는 처음 표시하는 짧은 안내 영상과 실제 라이브 영상이 다릅니다. 자동 수집기가 방송 화면의 재생 버튼을 눌러 라이브 영상이 재생되는지 확인하도록 수정했습니다. 방송 탭은 계속 음소거합니다. 페이지가 재로딩 중 잠깐 빈 주소로 표시될 때는 사용자 이동으로 판단하지 않고 다음 확인을 기다립니다.

공개 SOOP 방송에서 실제 확장 프로그램이 라이브 영상 재생을 시작하고 영상 시간이 증가하는 것을 격리 Chromium에서 확인했습니다. 로그인한 계정의 드롭스 적립과 모니터를 끈 밤샘 상태는 사용 환경에서 확인이 필요합니다. `chrome://extensions`에서 이 확장 프로그램을 **새로고침**하면 수정 사항이 적용됩니다.

## 1.5.6 — SOOP 방송 탭 반복 전환 방지

이미 재생을 시작한 SOOP 방송은 주기적인 재생 검사에 일시적으로 실패해도 먼저 백그라운드에서 복구를 시도합니다. 이때 보고 있던 탭을 SOOP 방송 탭으로 전환하지 않습니다. 새 방송을 처음 열거나 방송이 바뀔 때는 재생 시작을 위해 잠깐 활성화할 수 있습니다. 수정본을 불러온 뒤 확장 프로그램 관리 화면에서 새로고침해 적용하세요.

## 1.5.7 — SOOP 방송 주소 및 팝업 초기화 안정화

SOOP 방송의 `.com` / `.co.kr` 도메인 전환을 같은 방송으로 인식합니다. 팝업 초기화에 일시적인 오류가 나도 설정 컨트롤의 잠금이 풀립니다. 확장 프로그램 관리 화면에서 새로고침해 적용하세요.
